# Запуск Cannabis MCP

Сервер содержит девять инструментов. Общие расчёты, химические представления, контракты и экспорт находятся в `chem_repro/common`; поиск инструментов, планирование и отчёты остаются в CoScientist.

## Окружения

Распакуйте пакет в локальную папку вне облачной синхронизации. Нужны Python 3.12 и `uv`.

```bash
uv sync --frozen --python 3.12
uv run python scripts/setup_cannabis_workers.py \
  --directory "$PWD/workers" --output worker_configuration.json
```

Команда создаёт два изолированных окружения по включённым спискам версий: Chemprop/PyTorch для DMPNN и отдельное окружение для публичной реконструкции токсикологических моделей. Она скачивает зависимости, но не запускает обучение. Существующее окружение проверяется и при несовпадении версий остаётся неизменным. В конфигурацию записываются абсолютные пути, чтобы смена рабочей папки не приводила к повторному обучению в другом каталоге.

Для проверки уже установленных окружений без скачивания:

```bash
uv run python scripts/setup_cannabis_workers.py \
  --directory "$PWD/workers" --check-only \
  --chemprop-python /absolute/path/chemprop/bin/python \
  --tox-python /absolute/path/open-tox/bin/python \
  --output worker_configuration.json
```

Пути результатов в сгенерированном JSON указывают на новый каталог `workers/results`. Если результаты уже рассчитаны, явно укажите существующие абсолютные пути в соответствующих полях JSON. Сервер проверяет состав данных, код расчёта, настройки, версии и контрольные суммы сохранённых результатов. Чужие или несовпадающие результаты не считаются подходящим кэшем.

## Сервер и CoScientist

```bash
uv run python scripts/run_cannabis.py --configuration worker_configuration.json
```

Адрес по умолчанию: `http://127.0.0.1:7341/mcp`. Для другой машины передайте `--host 0.0.0.0` и `--public-base-url` с доступным CoScientist адресом. Порт задаётся через `--port`; внешний URL нужно изменить согласованно. Таблицы и структуры возвращаются как скачиваемые файлы с размером и SHA-256.

Из настроенного checkout CoScientist с работающими Postgres/Qdrant и сервисами эмбеддингов/ранжирования:

```bash
uv run python -m scripts.rag_tools.cli load /absolute/path/to/rag_registration.json
```

Поставляемый общий `rag_registration.json` регистрирует все три сервера: перед загрузкой запустите также Heracleum и Mannich либо сделайте отдельную копию JSON только с записью `cannabis-2026`. Ключ LLM нужен CoScientist, сами научные MCP-инструменты к нему не обращаются.

## Что исполняется и что нельзя объявлять воспроизведённым

- Аудит исходной выборки, докинговых профилей и остаточных взаимодействий выполняется на закреплённых публичных данных.
- RTE, DMPNN и их произведение вычисляются заново при отсутствии подходящего сохранённого расчёта. Это может быть длительное обучение; значения `iterations`, `max_epochs` и разбиения попадают в provenance.
- Отбор кандидатов возвращает отдельно опубликованные округлённые результаты Figure 4, новые обе вероятности, их произведение и ранги среди 2749 публичных запросов. Итоговая выборка статьи и её 44 аннотации CCD отсутствуют. Неизвестная аннотация не равна первичному метаболиту. Итоговый ответ остаётся `partial`.
- Девять эндпойнтов `fixed_public_v1` — объявленная публичная реконструкция. Оригинальных данных и весов Syntelly нет. Вложенный вариант `nested_paper2024_v2` требует отдельного реестра законченных проверенных расчётов, настройки Optuna и не устанавливается этим скриптом. Подмена оригинального Syntelly другой моделью не выдаётся за точное воспроизведение.
- Свежая установка зависимостей на произвольной платформе и полная сборка контейнера с обоими ML-окружениями не подтверждены проверкой только существующих macOS-окружений. Основной Docker-рецепт пока не включает эти два окружения.

Десять запросов C01–C10 находятся в `tests/e2e/prompts.jsonl`; ожидаемые вызовы и критерии отдельно в `tests/e2e/cases.json`. Не добавляйте численные эталоны из файла критериев в запрос модели. Прямой успешный вызов MCP не подтверждает правильность итогового отчёта CoScientist.
